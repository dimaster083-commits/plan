## Границы следующего изменения

Сохраняется принятая визуальная основаv5, палитра/компоновка, отсутствие
таймера отдыха, расчёт только по журналу, модель динамических нутриентов
и смысл0 веса тренировки. Не меняются права пользователя на данные.

В чат отправлен короткий bounded-вариант: поле граммов≥44px, сырой ввод
остаётся временным черновиком, фоновые напоминания не перекрывают вопрос
и не укорачиваютUndo. Реализация ожидает подтверждения поведения.
Пока выполнены только диагностика, её повтор и документирование.

Техническая граница: raw нельзя сопоставлять только по индексу/имени.
Копирование буквально равного рациона создаёт другую форму даже без
измененияserializedS; удаление соседнего одинакового продукта сдвигает
индексы. Любой будущий снимок identity для Undo снимается до мутации.

Простая FIFO вопросов может вклинить импорт между двумя подтверждениями
полного стирания. Предложен явный отказ позднему импорту с понятным
предложением повторить выбор после текущего вопроса; это рекомендация,
не выполненное исправление и не уже принятое новое решение владельца.

Физические телефоны/Safari/системная клавиатура, реальные архивы и квота
не проверены. Runtime/index/system/sw не изменены; новый cache/version
и новый полный релизный прогон будут только после исправлений.
