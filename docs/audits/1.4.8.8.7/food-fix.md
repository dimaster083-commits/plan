# BUG-0029 — черновики граммов основного рациона

Изменение согласовано владельцем; реализация 14–15.10.2026.
База `fd4c868`, прежний опубликованный runtime v6. Данные синтетические,
отдельные профили Chromium 320×568 и 390×844, Asia/Vladivostok.

## Причина и граница

`paintFood` строил поля из сохранённого журнала и терял неподходящий raw.
Суммы при этом были правильны: неверное число не записывалось. Исправление
не меняет это правило и не превращает raw в автосохранённый рацион.

Transient WeakMap identity списка/приёма/строки плюс дата связывает ввод
с конкретным продуктом. Map хранит только raw и признак ошибки, вне `S`.
Удаление соседнего дубля не переносит ввод. Копия/импорт создают новые
объекты, даже если JSON равен; чужой raw не наследуется. Валидный ввод
снимает raw, обновляет тот же журнал и прежние производные.

Undo использует sidecar identity, снятый до мутации: после JSON-отката
старые строки получают свои прежние identities. Кэш raw не откатывается,
поэтому ввод, сделанный после исходного действия, тоже сохраняется.
Снимок охватывает все сохранённые даты, включая ещё не показанные.
Иначе первый вход в «Еду» после начала тренировки всё ещё терял raw при Undo.
Снимки не угадываются по имени/граммам/позиции нового рациона.

Перезапуск страницы намеренно оставляет только валидный сохранённый журнал.
Неверный ввод остаётся на экране до перезапуска/явной замены рациона;
он не входит в JSON копии, localStorage, калории и КБЖУ. Пустое поле при
фокусе — черновик; уход с пустого поля по прежнему контракту записывает0.
Динамическая база нутриентов и её исторические итоги не менялись.

## Известное P3 — BUG-0033

Независимая диагностика: invalid raw → удалить строку настоящей кнопкой →
7100мс → redraw. В `foodUiRaw` остаётся1 элемент при0 строк и отсутствии Undo.
Это page-memory, не данные журнала; при перезапуске очищается. Очистка
недостижимых поколений отложена; деградация скорости не установлена.

Проверяются реальные кнопки, нативный файл импорта, чтение localStorage,
перезагрузка, литеральные вручную рассчитанные суммы, raw и aria-invalid.
Тесты не читают приватные identity-ключи. Дробные макросы сравниваются с
явными ожидаемыми числами с допуском1e-10 из-за binary floating point;
это исправление обвязки, не округление/изменение приложения.
Физические телефоны/Safari/реальная клавиатура и большой личный журнал
не покрыты. Полный GREEN не заявляется на основании focused-набора.
