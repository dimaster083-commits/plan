# «Фитнес для умных» (Д. Смирнов, 2010) — выжимка для приложения

## Плоскостная система (гл. 5)
Типы движений: ГЖ горизонт. жим, ВЖ вертик. жим, ГТ горизонт. тяга, ВТ вертик. тяга,
КД коленно-доминантные, ТД тазово-доминантные, ВПН (вращают плечо наружу), кор (передний/латеральный/задний + КПЧ), кардио.
Лесенка каждого типа: 1 — простейшее (новичку), 5 — самое «тяжёлое» по весу, 6 — унилатеральное (сложное).
ГЖ: жим в тренажёре → отжимания → жим гантелей лёжа → брусья (узко) → жим штанги лёжа (мост) → жим на блоке одной рукой стоя
ВЖ: супинированные отведения стоя → отжимания уголком → жим гантелей сидя (верт. спинка) → высокая тяга от колен → швунг жимовой → швунг одной гантели
ГТ: фронтальная тяга в тренажёре с упором → подтягивания на низкой перекладине → тяга гантелей лёжа на наклонной → тяга блока к животу узко → тяга штанги в наклоне с пола → тяга гантели в наклоне без опоры
ВТ: тяга верх. блока широко к груди → облегчённые подтягивания (ноги на скамье) → подтягивания широким к груди → подтягивания обратным средним → тяга верх. блока одной рукой
КД: разгибания голени (только если не может присесть) → болгарский сплит-присед → присед Зерхера → фронтальный присед → присед с низкой штангой → присед на одной ноге (на лавке)
ТД: сгибания голени сидя → ягодичный мостик одной ногой → гиперэкстензии наклонные → GHR/румынская тяга → становая с пола → румынская на одной ноге
ВПН (самое «весомое» — 4-е): L-отведения на блоке → подъём гантелей на грудь сидя → подъём одной гантели на грудь стоя → подъём штанги на грудь с лавки → рывок с лавки → рывок одной гантели с пола
Кор передний: скручивания на фитболе → планка (локти на мяч, ноги на скамье) → роллауты на фитболе
Кор латеральный: диагональные скручивания → боковая планка → наклоны в сторону с гантелью (дровосек)
Кор задний: гиперэкстензии на фитболе → ягодичный мостик на фитболе (изометрия) → наклоны со штангой стоя
КПЧ: L-отведения/приведения, лицевая тяга, обратные шраги на брусьях
Комплексные кор: выпады с гантелью над головой, присед со штангой над головой, присед с одной гантелью над головой
Мелочи: хват — сгибания Зотмана/молотки/подъёмы на бицепс, удержание дисков, вис на полотенце, фермер; трицепс — трицепсовый жим с гантелями на полу; икры — сидя в дни тяжёлых приседов (стоя грузит спину), пятки низко не опускать.
«Не великолепная семёрка» (вредные): присед Сизифа, жим ногами (в силовом стиле), тяга к подбородку стоя, французский жим, гакк-машина, концентрированные сгибания, разводки лёжа.
Нет «базовых/изолирующих»: базовое = то, что сейчас развиваешь.

## Разминка (гл. 6)
Задачи: местный разогрев работающих суставов; репетиция основной части; возбуждение ЦНС; техника; профилактика дисбалансов; ослабление мешающих мышц; ОФП; ≤10–15 мин, без утомления.
Шаги: (1) кардио 3–5 мин ТОЛЬКО перед КД/ТД или если ноги первые; (2) суставная разминка от мелких к крупным; (3) круг калистеники 2–3×6–8 без отказа (того же типа + ВПН + противоположная тяга + кор); (4) активный стретч агонистов + пассивный антагонистов; (5) мобильность; (6) специальная разминка.
Специальная разминка: повторов = половина первого рабочего подхода, но ≤8; вес +~20% каждый подход, повторы убывают; перед рабочим — 90% на 1–2. Пример 100×10: 20×5-6, 40×5, 60×4-5, 80×3-4, 90×1-2. Лёгкий вес → меньше подходов или без них.
Заминка: 1–2 кондиционных подхода 12–20 не до отказа; пассивный стретч работавших мышц 3–4×15–30 с; 5–10 мин спокойной ходьбы; суставная разминка наоборот.

## Прогрессии (гл. 8)
Простые: вес; повторы (сумма +1); сеты; средний тоннаж; скорость; сокращение отдыха; TUT (темп); усложнение упражнения; порядок упражнений.
Сложные: плотность (EDT: 2 упр. по 5 повт. с 10ПМ, 15 мин, +1 повтор); доля отказных сетов; исходное положение; анатомически невыгодное положение; эпюра (резина/цепи); стартовая точка; негативы; квазиизометрия; баллистика; центр тяжести; хват; без экипировки.
Схемы веса: постоянный (конст.), рост от сета к сету (п.), убывание (о.п.), пирамида, обратная пирамида, 1 тяжёлый в конце, 1 тяжёлый в начале, волна, хаос. «Рокировка» 3×10 → 10×3.
Рейтинг нагрузки упражнения: лёжа < сидя < стоя < в наклоне < вис; односуставное < многосуставное; тренажёр < блок/резина < своё тело < Смит < штанга < гантели; стабильная опора < нестабильная; билатеральное < смешанное < унилатеральное; изометрия < изотоника < плиометрия; малая амплитуда < полная; плечо рычага; минимальная исходная нагрузка.

## Виды сетов (гл. 9) — категория стажа: начинающие ≤1 год, опытные 1–2, продвинутые 2–3+
Обычные (все), кластерные/чередование А1/А2 (нач., опытн.), комби-сеты (все), с изменяющейся нагрузкой (прод.), круговые (оп., прод.), гибриды (оп., прод.), комплексы (прод.), скоростные 50–70% 1–3 повт. (прод.), изометрия (все, кроме ССС), суперсет антагонистов (оп.), двусет (оп.), трисет, частичные, дубликаты, 1,5 повтора, дроп (≤3 ступени −15–20%; не в становой и т/а), отдых-пауза, анатомическое соответствие, форсированные, форс. эксцентрика (прод.), эксцентрические (прод.), квазиизометрия (прод.), плиометрические (прод.), задержка пикового (все), форсированный стретч, постактивация, сет до отказа (1 в месяц).
Правило: чем ближе к отказу — тем проще упражнение.

## 13 заповедей программиста (гл. 10)
1. Равенство противоположностей по КПШ (все повторы вкл. разминку): ГЖ=ГТ, ВЖ=ВТ, КД=ТД, ВПН=вращающие внутрь (ГЖ+все тяги). Односуставное против многосуставного — ×1,5–2 повторов. Перекос в сторону ГТ, ВЖ, ТД — желателен.
2. Силовой баланс: 1ПМ жим лёжа = 1ПМ подтягивания обратным (+вес тела) = 1ПМ подъём на грудь; 1ПМ становая = 1,5 × 1ПМ присед.
3. Программа начинается с разминки. 4. Темп XYWZ (опускание, пауза внизу, подъём, пауза вверху), 2010 — «норм.», X — взрыв. 5. Схема регулировки веса (п./конст./о.п.). 6. Паузы отдыха. 7. Заминка.
8. Программа на 4–6 микроциклов минимум, ≤12 недель; у новичков смена каждые 2–3 недели. 9. Через день — оптимум, 3–4 тренировки в неделю. 10. Менять порядок упражнений каждые ~2 недели. 11. ≤6 упражнений основной части, ~20 сетов, час. 12. Долгосрочная периодизация. 13. Не зазнаваться.
Периодизация (год, ~36 недель): подготовительный 2–4 нед (ОФП, калистеника, унилатерал) → гипертрофия 4–8 (свободные веса, ≥8 повт., TUT 90–120 с/регион) → разгрузка 5–10 дн полного отдыха → сила 4–8 (только многосуставные, 1ПМ +2,5–5 кг) → мощность 4–6 (взрыв, прыжки; без разгрузки перед) → разгрузка → метаболический 4–6 (>12 повт., гибриды, круги, интервалы; −0,5–2% жира) → восстановительный 2–4 (2–3 тренировки/нед, гибкость, кор, МФР) → разгрузка → повтор.

## Тесты (гл. 3, 11)
Руфье-Диксон: (4×(P1+P2+P3)−200)/10, пульс за 15 с: покой; после 30 приседаний за 30 с (или 20); через 1 мин отдыха. <0 отлично, 0–3 очень хорошо, 3–6 хорошо, 6–10 удовл., 10–14 плохо, >14 очень плохо. Каждые 6–8 недель; рост индекса = переутомление.
Для выбора кардио: 10–14 — горизонтальный велик; 6–10 — небыстрая ходьба/эллипс; 3–6 — всё, включая интервалы. Начинать с 10–15 мин кардио, доводить до 30–40.
Пульс покоя: утром сидя, 3 дня, среднее; ≤72–78 к 30 годам. Давление ≤130/90 (стремиться к 120/80).
Ортопедический индекс: оценка 1–5 каждого сустава (плечи, локти, колени, голеностоп, таз, позвоночник): 1 травма, 2 отчётливая боль, 3 приемлемо/незначительная боль, 4 лёгкий дискомфорт под нагрузкой, 5 отлично. Не 5 везде — нет отличной формы.
Жир: хорошая форма 12–14%, герой ≤9%.
Годовой баланс: нормативы −1% в год после 30.
Тесты гибкости новичка (выбор упражнений): 1) плечевой пояс А (руки назад сидя) → вариант ГЖ; плохо — только тренажёр/калистеника + стретч грудных между тягами; 2) плечевой пояс Б (руки за голову лёжа, поясница прижата) → плохо: запрет ВТ, только тяги к животу/фронтальные; средне — ВТ без «за голову»; 3) вращатели плеча → плохо: ГТ ×1,5–2 к ГЖ, тяги обратным хватом, 1–2 ВПН, супинированные отведения, стретч пронаторов; 4) тест Томаса (сгибатели бедра) → плохо: запрет приседов и жима ногами, разгибания/сплит-приседы + стретч сгибателей бедра между сетами; 5) Seat&Reach (задняя поверхность) → плохо: запрет гиперэкстензий/румынских/сгибаний сидя, только ягодичные мостики; 6) лордоз ладонью у стены: норма — любой пресс; плоский — обратные скручивания/подъём корпуса; гипер — только обычные скручивания, ТД ×1,5–2 к КД; 7) медленное отжимание 10 с — ломается: только скручивания, держит — можно планки; 8) Руфье → кардио.

## Новичок (гл. 12)
Ошибки: дробить на 13 односуставных; 15–20 повторов с первого дня (правильно — путь 6–8 → 15); круговые новичку; хотеть похудеть/набрать в первые полгода (задачи: ОФП, техника, привычки питания); тренироваться редко (новичку — 4 коротких в неделю); не бояться.
Принципы: 1) набор: ГЖ, одна тяга (по тесту), КД, ТД, 1–2 ВПН, передний кор; 2) калистеника, тренажёры не дольше 1–2 мес; 3) линейная периодизация (15→6 повт., рост сетов), после 3–6 мес — чередование лёгких/тяжёлых; 4) смена программы каждые 2–3 недели; 5) короткие микроциклы (микроцикл = 1–2 тренировки); 6) интервальное кардио (разминка 3–5 мин, 1 мин очень быстро / 2–3 мин спокойно ×5–7); 7) отдых по самочувствию (пульс ≈ покоя).
Этап 1 (6 мц по 2 тренировки, вес постоянен, не до отказа, темп норм, отдых по самочувствию):
 A1 отжимания на коленях / A2 верт. тяга к груди широко; B1 подъём гантелей на бицепс сидя / B2 отведения гантелей стоя; C1 болгарские сплит-приседы / C2 ягодичный мостик одной ногой — 2×8, 2×10, 3×10, 3×12, 3×15, 1–2×20. Кор: скручивания на полу 3×12, 2×15, 3×15, 2×20, 3×20, 3×25. Разминка: кардио 3–5, круг: присед держась за опору 2×6-8, скручивания 2×8-10, гиперэкстензии на фитболе 2×6-8. Заминка: ходьба 5–10 мин, +5 мин/нед до 30.
Этап 2 (3 схемы по 2 тренировки, затем повторить с бо́льшим весом; 1 разминочный 60%×5-8; темп 2021):
 A1 жим гантелей лёжа / A2 тяга блока к животу узко; B1 верт. тяга обратным хватом / B2 отведения гантелей сидя; C1 присед Зерхера на лавку / C2 гиперэкстензии с отягощением — 2×20 (отдых 75 с), 2×15 (70), 3×12 (60). Кор: планка 1×10/15/20 с (2012); скручивания/обратные 2×20/25/30 (1010); L-вращения с бодибаром стоя 2×20. Кардио интервалы 4×(1 мин быстро/3 мин).
Этап 3 (18 тренировок, каждая — следующая схема; «+» подряд без отдыха; жиросжигающий уклон):
 1 жим штанги лёжа + поочерёдные подъёмы на скамью с гантелями; 2 облегчённые подтягивания + фронтальный присед; 3 тяга блока к груди широко + жим гантелей сидя — 3×12+2×20 (90 с), 3×10+2×15 (75), 4×8+3×12 (60), 4×5+3×10 (60). Кор: планка ноги на фитболе 1×15/20/30 с/макс; дровосек верх. блок 2×20/25/30/30 в сумме; подъём коленей + скручивания на фитболе 2×10+2×25, 2×12+2×25, 2×15+2×30, 1×20+1×макс. Кардио 6×(1/2).
Этап 4 (2 дня, 6 мц по 4 тренировки: через день, после 4-го дня 2 дня отдыха; вес постоянен; с мц3 1–2 разминочных 50–70%×6-8; не до отказа кроме мц6):
 Схема для всех пар: 2×15 (60 с), 2×12 (70), 3×10 (80), 4×8 (90), 5×6 (120), 1×20 (60).
 День 1 (ГТ, ГЖ, КД, кор): A1 жим гантелей на наклонной / A2 тяга штанги в наклоне обратным; B1 брусья / B2 тяга гантели в наклоне без опоры; C1 жим ногами / C2 подъёмы на платформу (3011); икры сидя 2×30, 2×25, 2×20, 3×15, 3×12, 1×50; планка 1×20..60 с (+5); скручивания на фитболе 2×20/25/30; L-вращения 2×20. Кардио: гребля 20–30 мин.
 День 2 (ВТ, ВЖ, ВПН, ТД, кор): A1 жим гантелей сидя / A2 подтягивания широко; B1 рывки со штангой от колен (11X1) / B2 верт. тяга узким прямым; C1 румынская с гантелями / C2 сплит-приседы с гантелями; икры стоя; планка; обратные скручивания на наклонной; L-приведения на блоке 2×20.
Этап 5 (12 мц по 2 тренировки = 6 мц дважды; волна; 1–2 разминочных 50–70%; не до отказа):
 Схема: 2×15 (45 с), 3×8 (60), 2×12 (45), 4×6 (65), 2×10 (45), 5×5 (75); икры 2×30, 3×12, 2×25, 3×10, 2×20, 3×8.
 День 1: A1 жим штанги лёжа / A2 тяга блока к груди широко (1010); B1 жим гантелей на наклонной / B2 тяга штанги в наклоне; C1 присед со штангой на спине / C2 гиперэкстензии наклонные одной ногой; икры сидя; планка на одном локте 1×20..60 с; подъём ног в висе + скручивания на фитболе 2×10+2×20 → 2×15+2×30; L-вращения 2×20. Кардио: гребля интервалы 4×(1/2).
 День 2: A1 жим штанги стоя / A2 верт. тяга широко к груди; B1 подъём штанги на грудь от колен / B2 подтягивания обратным; C1 становая с пола / C2 болгарские сплит-приседы с гантелями; икры стоя (1010); планка на одном локте; подъёмы таза на скамью + обратные скручивания; L-приведения на блоке 2×20.

## Гипертрофия (гл. 13)
Принципы: тренировка каждые 48 ч; общие (всё тело); разнообразие стимулов при силовой прогрессии в многоповторных максимумах (10ПМ +5 кг = рост); TUT 90–120 с на регион за тренировку; 10–15 повторов в приоритете. 5 кг сухой массы в год — оптимистично.
Таблица TUT: 4×5 (2012) 100 с; 6×3 (2022) 108; 3×8 (2011) 96; 3×12 (2010) 108; 2×15 (2010) 90; 2×25 (1010) 100.
Волна для одного упражнения (3 тренировки/нед): мц1 4×5, 2×15, 3×8; мц2 6×3, 3×12, 3×10; мц3 5×5, 2×20, 2×12; → мц1.
Программа 1 (Фомин, линейная «15→2»): 3 дня. Начать с веса на лёгкие 15/12/8 повторов, +2,5 или 5–10 кг в неделю, стараясь сделать стартовое число; главный — первый сет, остальные по самочувствию; дошли до финала (2) — назад к стартовому весу (+2,5–5), снова 15. Когда жим/присед/тяга дошли до 2 — меняем вариант наполнения (3 цикла). Вес постоянен внутри тренировки. Отдых в основных — до полного восстановления.
 Цикл 1 Д1: жим лёжа 3 (15→2, 2011); становая 3 (8→2, 2111); тяга штанги в наклоне 3 (15→6, 2010); верт. тяга к груди 3 (15→6); икры стоя 2 (30→15, 60 с); скручивания на фитболе 3×30–35 + планка (фитбол, ноги на скамье) 3×30–60 с.
 Д2: жим лёжа узко (−10 кг от Д1) 3 (15→8); швунг жимовой 3 (10→6, 11X1); лицевая тяга 3 (15→6); подъём штанги на бицепс 3 (15→6); хват 1–2 упр по 2; КПЧ 1–2 упр по 2; икры в 45° тренажёре 4 (15→10); обратные скручивания на наклонной 3×макс.

## Жиросжигание (гл. 15)
Суть: похудение — катаболизм; ставка на кортизол и EPOC, а не на малоинтенсивное кардио, «лёгкое железо» и голод. Дробное питание каждые 2–3 ч. Утренние тренировки. Признак EPOC — сонливость и «жар» после тренировки.

## Выносливость (гл. 16)
Специфична. Дорожка — ходьба с уклоном (+1° ≈ +2,5%). Принципы: специфичность; план (рекорд на 4–6 мц, перед рекордом сбросить); 4–8 недель; 1–2 силовых в начале для сохранения силы (≤5–10% потерь); 3–4 раза в неделю с разной интенсивностью; слабые звенья.
Методы: повторный (+нагрузка каждый мц); интегральный (5–10 отрезков, отдых 60→0 с); волнообразный (рекордный / кондиционный / повторный день).

## Гибкость (гл. 17)
Противопоказания: недавние переломы/вывихи, обострение «-итов», остеопороз/артроз, резкая боль, перегруженный сустав, тромбы/варикоз.
Подвижность нужна: голеностоп, таз, грудной отдел, плечи; стабильность: колени, поясница, шея. Пик 14:30–16:00.
Методы: активный статический/динамический (безопасны, можно до и между подходами); пассивный статический (после силовой или отдельно; между сетами только антагонисты); пассивный динамический; агонистический; антагонистический; прогрессивный; изометрический; PNF; AIS; баллистический.
Дозировка: 4 подхода на мышцу, 3–5 упражнений, статика 30 с, отдых = длительности, ежедневно, секунд стретча ≈ секундам силовой работы мышцы (×1,5 для прибавки).
Упражнения «Х» и замены: барьерный шаг → ардха-падмасана; европейский присед → азиатский; лягушка → на коленях с упором на предплечья; наклон стоя ноги вместе → ноги врозь/сидя; прогибы в пояснице → на фитболе; резкие скручивания → медленно в грудном; вис вниз головой → лёжа; плуг → округление сидя; шпагаты → по половинкам.

## Быстрота (гл. 18)
Реакция, кор, агонисты и антагонисты, стретч-рефлекс, техника. Скоростные: простые многосуставные, ≤15 с, полный отдых, ≥5 сетов, в начале тренировки.

## Восстановление (гл. 19)
Пассивный отдых 4–14 дней после 6–8 недель. Разгрузка каждые 2–4 недели: интенсивность −15–30%, объём меньше, упражнения проще. Кондиционный тренинг 2–3 по Боргу. Сон 7–8 ч (8–10), дневной 15–25 мин, прохладно, темно, без экранов, до полуночи. Медитация 5–10 мин. МФР роллером: 10–12 движений, амплитуда 5–10 см.

## Ограничения (гл. 20; не заменяет врача)
Всем: фронтальный/Зерхер/болгарский вместо высокого грифа; глубже прямого угла; без жима ногами и поясов/бинтов; становая на одной ноге или со стоек без пола; «грудные» разгибания вместо гиперэкстензий; стоя на полусогнутых; без односуставных; жим с паузой 1–2 с; при больной спине — дровосеки/«молитва»; поесть перед тренировкой.
Гипертония: без натуживания, рук над головой, лёжа вниз головой, максимумов и отказа; начинать с периферии, кардио ≥половины и первым; отдых полный. Гипотония: кардио основа, объём −30%. Внутричерепное: как гипертония, без Зерхера/жима ногами, объём −20–30%. Остеохондроз грудной/шейный — осторожно лёжа. Сколиоз — осторожно с руками над головой. Глаза — без больших весов, натуживания, наклонов. Артрит — вне обострения. Артроз — нагружать мышцы косвенно. Плоскостопие — без «сплющивающих». Варикоз — динамика, без стояния и велика. Диабет — ходьба; инсулин с врачом. После операций — втягивание → напряжение → скручивания.

## Спорт (гл. 21)
Принципы: стоя, ноги унилатерально, кор, «задняя цепь», умеренный объём, калистеника, плиометрика, сила и быстрота, функциональная гибкость. Футбол — смена направления; бокс — кор и тяги, без приседа со штангой; плавание — рывки; теннис — ВПН; хоккей — приводящие, фронтальный присед; единоборства — плечевой пояс, косые, присед можно; баскетбол — не приседать; горные лыжи — билатерально, изометрия.
