## Как вести реестр

- Подтверждённые ошибки получают постоянные ID `BUG-0001`, `BUG-0002`, …
- Локальные номера находок агентов связываются с одним постоянным ID после
  проверки корневым агентом; похожие симптомы не считаются одной причиной автоматически.
- Ограничения и непроверенные предположения имеют отдельные ID `LIMIT-…`.
- Карточка: версия/среда, источник сообщения, приоритет, шаги, ожидаемое/фактическое,
  причина с местом исходника, затронутые экраны, воспроизводящая проверка,
  версия исправления, результаты отмены/перезагрузки/связей, публикация, ответ владельца.
- Статусы: сообщено → воспроизведено → исправлено → проверено → опубликовано
  → подтверждено владельцем. Нельзя перескакивать через неизвестные состояния.
- Повтор: тот же ID возвращается в «сообщено/воспроизведено», предыдущие
  доказательства остаются, записываются новая версия и условия повторения.
- Приоритеты: P0 массовая/невосстановимая потеря данных или невозможность открыть;
  P1 основной рабочий сценарий или ошибочное удаление с доступной отменой;
  P2 неверные итоги или отдельная функция; P3 удобство/оформление.

### LIMIT-002 — нулевой вес строки

- Тип: действующая договорённость, возможная неоднозначность интерфейса.
- Версия: 1.4.8.8.1.
- Пустая строка веса и 0 используют общий вес упражнения. Без отягощения
  общий вес должен быть 0. Изменение смысла 0 потребует отдельного решения
  о старых данных; само по себе это не вновь обнаруженная ошибка.
- Статус: ограничение; не исправлялось и не мигрировалось.
- Источник: `CLAUDE.md`, `docs/audits/2026-10-09-linked-app.md`.

### LIMIT-003 — неполный снимок исторического расписания

- Тип: известный исторический случай, требуется отдельное воспроизведение.
- Версия: 1.4.8.8.1.
- Исторический снимок хранит тип/название, не полный состав упражнений.
  Удаление всех упражнений шаблона и исторический порог серии не покрыты
  узкой правкой `planWeek`; общая историческая неизменность не доказана.
- Статус: нуждается в проверке; не объявлен исправленным.
- Источник: `docs/audits/2026-10-09-linked-app.md`, раздел «Ограничения».

Часть про порог серии воспроизведена как BUG-0013. В проходе 13.10 удаление
последнего упражнения и заполнение прежде пустого слота воспроизведены
как BUG-0021. Для будущих правок введён снимок boolean eligibility `r.pe`;
он не восстанавливает неизвестный состав уже изменённого старого плана.
Полный исторический состав упражнений/норм мышц не реконструирован;
LIMIT-003 целиком не закрыт.
